Connected skills: the take-home sheet

AI Brown Bag #4 · August 17, 2026 · The skill stops asking for the material and goes to get it
1

The one-line model

connectors give access, skills teach the how
ConnectorThe plug into a tool you already use: Gmail, Calendar, Granola. Claude can go and get the material itself.
SkillThe procedure: what to fetch, what to check, what to produce. The same task done the same way every time.
ArtifactThe output as a page you can scan and click, not a wall of text.
2

What a connector actually is

MCP underneath, packaged for you
  • Claude sees what you can see, nothing more. It reads through your account. A colleague running the same skill gets their inbox and their calendar, not yours
  • You sign in once. The first use of a connector asks you to authenticate, then it holds
  • On at BFA today: Gmail, Google Calendar, Granola and Zoom. The connectors menu in any new chat shows the current list
  • Underneath is MCP, an open standard for plugging tools into AI. "Connector" is claude.ai's packaging of it
3

Telling a skill to use a connector

plain English, no code

Brief it the way you would brief a person. From the morning-briefing skill in today's demo:

Google Calendar: today's events. Note the calendar timezone and use it for every time in the briefing. Skip events the user has declined.

Gmail: the inbox from the last three days. Before flagging a thread as waiting on the user, check who sent the last message: if it was the user, the thread is not waiting on them.

The pattern: name each source, say what to pull, say what to check before believing it. Then gather everything first and write once.

4

The guardrails that make it trustworthy

four lines for every connector skill
  1. Trace everything. Every meeting, email and action item in the output traces to a real message, event or note. Never invent one
  2. Name failures. If a source is unavailable or empty, say so in one line and build from what remains. Never fill a gap with something plausible
  3. Read freely, change nothing. Gather from any connected source, but never send, reply, accept, decline or move anything. Suggest; the user decides
  4. Verify before you flag. Give the skill its checks, like the last-message check in section 3

The most expensive failure is number 1: one invented meeting costs you trust in all the real ones.

5

Making the output an artifact

design once, render every time
  1. Design the page once. Show Claude a finished example of the output and ask for a single-file HTML page: your colours, collapsible sections, a summary up top
  2. Freeze it into the skill. Save it in reference/ with the real content replaced by labelled slots
  3. Tell the skill to use it. A "How to present it" section: render one artifact from the skeleton, copy the style block verbatim, fill only the slots, plain-text fallback

Pointers: collapsible sections are plain HTML (<details> and <summary>), no JavaScript. And keep counts honest: a badge that says 4 has 4 items behind it.

in the Drive folder, install it today

7

Let Claude build yours

attach one finished example, paste this

I want to turn a task I do regularly into a Claude skill. Attached is a finished example of the output. The inputs live in: [for example, my calendar / Gmail threads with this partner / Granola notes].

Please: (1) ask me up to five questions about anything you would otherwise guess; (2) write a complete SKILL.md with name and description frontmatter, description written so it triggers reliably; (3) include a section naming which connectors to read, what to pull from each, and what to do when one is unavailable: say so in one line, never invent; (4) add rules: every item traces to a real message, event or note, and Claude reads freely but never sends or changes anything; (5) if the output works better as a page than prose, design an HTML skeleton in reference/ and render it as an artifact, with a plain-text fallback; (6) package it as a zip.

9

When it misbehaves

the five failures and their fixes
  • The skill never fires. The description line, still. Session 3's cheat sheet, section 4
  • Claude asks you to paste material it should fetch. The skill never names the source. Add the gather block from section 3
  • "I could not access Gmail." You have not authenticated that connector. Connectors menu, sign in once
  • It reports a meeting or email you cannot find. The guardrails are missing. Add the four lines from section 4
  • The output came back as plain text. Artifacts are off, or the skill has no "How to present it" section
